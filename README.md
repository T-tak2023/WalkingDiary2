# ウォーキングダイアリー (Walking Diary)

## サイト概要
ウォーキングダイアリーは、気ままな散歩をやさしく記録できるウェルネスサイトです。自動ルート記録と歩数トラッキングを軸に、写真や日記、場所のトリビアを添えて散歩の思い出を残せます。添付のモザイクタイルの配色を意識し、植物の蔓のように伸びやかな雰囲気をデザインで表現しています。

### 主な特徴
- **ルートを自動で記録**: スタート/ストップ操作だけでその日のルートを保存。
- **歩数を記録**: 歩いた距離と歩数を指標として可視化。
- **写真・日記を添える**: その日の気分や写真を記録し、散歩の体験を物語として残せます。
- **トリビアをお届け**: 立ち寄った場所に関する歴史・雑学情報を自動で提案。

## プロジェクト構成
- `index.html`: エントリーポイント。
- `src/App.jsx`: メインUIと散歩ログの状態管理。
- `src/styles.css`: タイルから着想を得た配色やレイアウト。
- `package.json` / `vite.config.js`: Vite + React によるビルド設定。

## 必要なツール
- Node.js 18 以上
- npm 8 以上

## ローカルでの確認方法
1. 依存関係をインストールします。
   ```bash
   npm install
   ```
2. 開発サーバーを起動します。
   ```bash
   npm run dev
   ```
3. ブラウザで `http://localhost:5173` を開きます。
4. 本番ビルドを作成したい場合は次を実行します。
   ```bash
   npm run build
   ```

## Vercel でのデプロイ手順（ノーコードでも安心）
1. [Vercel](https://vercel.com/) にアクセスし、無料アカウントを作成またはログインします。
2. 画面右上の **「New Project」** を押して GitHub 連携を許可します。
3. このリポジトリを GitHub にアップロードしたら、Vercel のプロジェクト一覧から対象リポジトリの **「Import」** を選択します。
4. **Framework Preset** に「Vite」が自動で設定されます。もし空欄の場合は手動で Vite を選びます。
5. **Build Command** は `npm run build`、**Output Directory** は `dist` のままでOKです。
6. 「Deploy」をクリックすると自動でビルドとデプロイが始まります。数分で完了し、公開URLが表示されます。
7. 公開後は「Visit」ボタンからサイトを確認できます。更新したい場合は、GitHub に変更を push するだけで再ビルドされます。

## ビルドで困ったときのトラブルシューティング
- **Node.js のバージョンが古い**: Vercel またはローカル環境で Node 18 以上を選択してください。
- **依存関係エラーが出る**: `package-lock.json` がないため `npm install` で最新の依存関係が取得されます。再インストール後に `npm run build` を試してください。
- **Vercel のビルドが失敗する**: プロジェクト設定の Build Command が `npm run build`、Output Directory が `dist` になっているか確認し、環境変数は不要なので空のままにしてください。
- **デザインのフォントが異なる**: Google Fonts がブロックされている可能性があります。必要であれば `index.html` の `<link>` タグをローカルフォントに置き換えてください。
